# threads-media

Public images for @robin.ai.lab Threads drafts in donetake/threads.

The Threads API fetches post images by URL, and donetake/threads is private, so screenshots we make ourselves (charts drawn by a page's JavaScript, tables, settings screens) are kept here and linked as `raw.githubusercontent.com` URLs.

- One folder per draft date: `YYYY-MM-DD/<name>.png`
- JPEG or PNG only, at most 1440 px wide
- Each image is a capture of a public page; the source is listed below
